Свойство mask-clip

Свойство mask-clip устанавливает область элемента, в пределах которой будет отображаться маска. Оно определяет, какие части элемента будут затронуты маскированием, а какие останутся видимыми без изменений.

Синтаксис

селектор { mask-clip: значение | no-clip; }

Значения

Значение Описание
border-box Маска применяется к области, включая границы элемента.
padding-box Маска применяется к области, включая padding, но не границы.
content-box Маска применяется только к содержимому элемента.
margin-box Маска применяется к области, включая margin (экспериментальное).
fill-box Маска применяется к bounding box объекта (для SVG).
stroke-box Маска применяется к stroke bounding box (для SVG).
view-box Маска применяется к viewbox (для SVG).
no-clip Маска не ограничивается областью элемента.

Значение по умолчанию: border-box.

Пример . Применение mask-clip к разным областям

Сравним различные значения mask-clip на элементе с границами и отступами:

<div class="box border-box">border-box</div> <div class="box padding-box">padding-box</div> <div class="box content-box">content-box</div> .box { width: 200px; height: 100px; margin: 20px; padding: 20px; border: 10px dashed black; background: linear-gradient(45deg, red, blue); mask-image: linear-gradient(to right, black, transparent); mask-size: 100% 100%; mask-repeat: no-repeat; display: inline-block; } .border-box { mask-clip: border-box; } .padding-box { mask-clip: padding-box; } .content-box { mask-clip: content-box; }

:

Пример . Использование no-clip

Демонстрация значения no-clip, когда маска выходит за пределы элемента:

<div id="elem"></div> #elem { width: 200px; height: 200px; background: linear-gradient(45deg, red, blue); mask-image: radial-gradient(circle, black 50%, transparent 70%); mask-size: 300px 300px; mask-position: center; mask-clip: no-clip; border: 2px solid black; }

:

Пример . SVG с разными значениями mask-clip

Применение различных значений к SVG-элементу:

<svg width="400" height="200"> <defs> <mask id="mask1" maskContentUnits="objectBoundingBox"> <rect x="0.1" y="0.1" width="0.8" height="0.8" fill="white"/> </mask> </defs> <rect x="10" y="10" width="180" height="180" fill="blue" mask="url(#mask1)" mask-clip="fill-box"/> <rect x="210" y="10" width="180" height="180" fill="red" mask="url(#mask1)" mask-clip="view-box"/> </svg>

:

Смотрите также

  • свойство mask-origin,
    определяет исходную позицию маски
  • свойство mask-image,
    задает изображение для маски
  • свойство mask,
    сокращение для всех свойств маскирования
  • свойство clip-path,
    создает обтравочную область для элемента
