Таблица date_format_type

Таблица date_format_type является системной таблицей Drupal, которая служит для хранения метаинформации о различных типах форматов даты и времени. Каждый тип формата представляет собой именованный набор настроек, который может быть использован для единообразного отображения дат в разных частях сайта.

Поля

Поле Тип данных Описание
type varchar(64) Машинное имя типа формата. Первичный ключ таблицы. Должно быть уникальным.
title varchar(255) Человекочитаемое название типа формата (например, "Короткий", "Средний", "Длинный").
locked int Флаг, указывающий, является ли тип формата заблокированным (защищенным от изменений через административный интерфейс). 1 означает заблокирован, 0 - разблокирован.

Как это работает

Drupal использует систему типов форматов для абстракции от конкретных строк формата PHP (например, d/m/Y). Вместо того чтобы жестко прописывать формат в коде, разработчик использует машинное имя типа (например, short, medium), а фактический формат строки настраивается администратором в разделе Администрирование > Конфигурация > Региональность и язык > Форматы даты и времени.

Связь между типом формата (date_format_type) и конкретной строкой формата (например, m/d/Y - H:i) хранится в таблице date_format_locale. Это позволяет иметь разные форматы для разных языков.

Заблокированные (locked = 1) типы форматов, такие как short, medium, long, предоставляются ядром Drupal и не могут быть удалены. Пользователь может создавать свои собственные типы форматов (locked = 0) через административный интерфейс.

Для вывода даты в нужном формате используется глобальная функция format_date() или методы DrupalDateTime, где в качестве параметра $type передается машинное имя из этой таблицы.

Пример SQL-запроса

Получить список всех типов форматов дат можно простым запросом:

SELECT * FROM date_format_type;

Посмотреть все типы форматов вместе с их настройками для текущего языка:

SELECT dft.type, dft.title, dft.locked, dfl.format FROM date_format_type dft LEFT JOIN date_format_locale dfl ON dft.type = dfl.type WHERE dfl.langcode = 'ru';

Смотрите также

  • таблицу date_format_locale,
    которая хранит конкретные строки формата для каждого типа и языка
  • таблицу cache_config,
    в которую кэшируются настройки форматов дат
  • таблицу config,
    где хранятся конфигурации форматов дат в формате YAML
  • таблицу locales_source,
    где могут храниться переводы названий типов форматов
