Редактирование записи в PhpMyAdmin

Редактировать записи в PMA можно использовать с помощью двух вариантов. Ниже рассмотрим их подробнее.

Пример

Давайте изменим имя нашему пользователю. Для этого перейдем во вкладку Browse и нажмем на иконку с карандашом:

После этого откроется вкладка Insert с инпутами, содержащими данные нашей записи. Давайте изменим имя на 'user+'. После чего нажмем на кнопку Go:

Если изменения применились, то вас перенаправит на страницу с содержимым таблицы. Также в ее верхней части вы увидите сработавший SQL запрос:
