Бирор икки p ва q туб сонлари берилган, ҳамда улар р3 (mod 4), q3 (mod 4) шартларни қаноатлантирадиган бўлсин.

Ушбу

p ва q туб сонлар  -  ёпик калитлар,

n = p*q эса  -  очиқ калит хисобланади.

Берилган М маьлумотни ШИФРЛАШ учун

С =M2 (mod n)      (1)

формуладан фойдаланилади.

ДЕШИФРЛАШ учун эса қолдиклар ҳақидаги Хитой теоремасига мувофиқ қуйидаги икки квадратик таккосламани ечамиз.

Кабул килувчига p ва q туб сонлари маьлум бўлгани учун С=M2 (mod p) ва С=M2 (mod q) яьни, ҳар бир квадратик таккосламани ечиб:

m1 = C(p+1)/4 (mod p)

m2 = (p- C(p+1)/4) (mod p)

m3 = C(q+1)/4 (mod q)

m4 = (q- C(q+1)/4 ) (mod q)

кейин эса а=q(q-1 mod p), b=p(p-1 mod q) бутун сонлар танланади.

У холда (1) квадратик таққослама ечимлари қуйидагилардан:

М1 = (а*m1 + b*m3 ) (mod n)

M2 = (a*m1 + b* m4) (mod n)

M3 = (a*m2 + b*m3) (mod n)

M4 = (a *m2+ b*m4) (mod n)

иборат. Шу туртта ечимдан қайсидир бири М га тенг, лекин кайси бири.

Бу муаммони ечишнинг битта усули берилган маьлумотга шифрлашдан олдин бирор сўз боши (заголовка) қўшиб қўйиш лозим бўлади. Мазкур схеманинг мураккаблиги квадратик таққослама мураккаб модулга эга бўлган ечимларини топиш масаласига асосланган. Бу масаланинг ўзи эса берилган n сонини туб кўпайтувчиларга ажратиш масаласига эквивалентдир.
